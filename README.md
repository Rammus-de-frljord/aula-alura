🎬 Guiminamflix
Bem-vindo ao Guiminamflix — um projeto simples e divertido que simula uma plataforma de streaming com tema do universo do Homem-Aranha! 🕷️🕸️

📄 O que é isso?
Esse projeto é uma página HTML que exibe:

Um título estilizado com o nome do site.

Um destaque para o filme "Através do Aranhaverso", com trailer incorporado direto do YouTube.

Uma seção com miniaturas clicáveis de outros vídeos relacionados, também vindos do YouTube.

🛠️ Como funciona?
A estrutura está dividida em três partes principais:

1. Cabeçalho (<header>)
Mostra o nome da plataforma: GUIMINAMFLIX — como se fosse uma versão divertida da Netflix.

2. Seção de destaque (.chamada)
Aqui aparece:

O título do filme em destaque.

Uma hashtag temática (#homem-aranha).

Um trailer incorporado via <iframe> do YouTube.

3. Seção de categorias (.categoria)
Mostra uma lista de miniaturas de vídeos (thumbnails) que funcionam como links clicáveis para outros trailers ou conteúdos relacionados.

🎨 Estilo e fontes
O projeto usa a fonte estilosa Chakra Petch, importada do Google Fonts, para dar um visual moderno e geek.

Além disso, o visual da página é definido no arquivo externo styles.css. (Certifique-se de ter esse arquivo com os estilos definidos, senão a página pode ficar sem formatação!)

▶️ Como usar
Abra o arquivo .html em um navegador (como Chrome ou Firefox).

Clique nos vídeos para assistir aos trailers.

Edite e personalize o conteúdo como quiser!

💡 Ideias para melhorar
Adicionar mais categorias (animação, ação, etc.).

Criar um menu de navegação.

Tornar a página responsiva para celular.

Incluir uma seção de login ou perfil de usuário (só por diversão!).

🚀 Dica final
Esse projeto é ótimo para praticar HTML, usar iframes, trabalhar com estilização via CSS e organizar conteúdo visualmente.

Divirta-se criando seu próprio streaming geek! 🎥🍿
